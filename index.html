Maintain Stroke Width

Keeps the stroke width consistent even when you scale the layer.

value / length(toComp([0,0]), toComp([0.7071,0.7071])) || 0.001;

Maintain Scale (Parented)

Keeps the layer's visual scale locked, even if the parent layer is scaled.

s = []; ps = parent.transform.scale.value; for (i = 0; i < ps.length; i++){ s[i] = value[i]*100/ps[i]; } s

Bounce Animation

This makes the Bounce Animation.

freq = 3; decay = 5; amp = 50; t = time - inPoint; value + amp * Math.sin(freq * Math.PI * 2 * t) / Math.exp(decay * t);

Bounce Animation_Advance

This is the same Bounce Expression what is unique in this is there is some other properties which let's you control where you want you shape after the bounce and more.

// How far off-center the initial drop is (20%) initialDrop = 200; // How much bounce area after the drop (5%) bounceArea = 10; // Bounce frequency and decay freq = 100; decay = 10; t = time - inPoint; duration = .5; // Duration of the entire animation in seconds // Calculate the center position of the comp centerY = thisComp.height/2; // Calculate base position (starts at center-initialDrop, moves to center) basePos = linear(t, 0, duration/2, centerY-initialDrop, centerY); // Calculate bounce (only after half the duration) if (t < duration/2) { bounce = 0; // No bounce during initial drop } else { // Time since bounce phase started bounceTime = t - duration/2; // Create diminishing bounce within the bounceArea bounce = bounceArea * Math.sin(freq * Math.PI * 2 * bounceTime) / Math.exp(decay * bounceTime); } // Combine base position and bounce basePos + bounce;

Automate Scale

This automate the scall over the multiple layers /shapes all you have to do is add a null named "CONTROLER" and then apply 2 silder control named "Select" "Padding" and now you have a animation Which is responseve and well mentioned

Keep Keyframes Working

Allows you to still use keyframes alongside an expression. The expression adds to the keyframed value.

+value

Invert Value (Negative)

Flips the animation to the opposite direction (e.g., Rotation 90 becomes -90).

*-1

Property Posterize Time

Lowers the frame rate of a specific property (creating a stop-motion look) without affecting the whole layer.

posterizeTime(4); value

Advanced Loop (PingPong)

Loops the animation back and forth. 'numKeyframes = 1' restricts it to the last section.

loopOut(type = "pingpong", numKeyframes = 1);

Advanced Loop (Offset)

Continues the animation in the same direction forever, adding to the previous value.

loopOut(type = "offset", numKeyframes = 0);
