Maintain Shape's Stroke Width

Keeps the stroke width of a shape layer consistent even when you Scale the shape layer itself from the Transform property.

Shape Layer > Contents > Rectangle > Stroke > Stroke Width

value / length(toComp([0,0]), toComp([0.7071,0.7071])) || 0.001;

Maintain Shape's Scale (Parented)

Keeps the layer's visual scale locked, even if the parent layer is scaled.

Shape Layer > Contents > Rectangle > Rectangle Path > Size

s = []; ps = parent.transform.scale.value; for (i = 0; i < ps.length; i++){ s[i] = value[i]*100/ps[i]; } s

In Bounce Animation (Left - Right)

This makes Bounce in Animation.

Shape Layer /Image /Video > Position

freq = 3; decay = 5; amp = 50; t = time - inPoint; value + amp * Math.sin(freq * Math.PI * 2 * t) / Math.exp(decay * t);

In Bounce Animation (Top - Bottom)

This is the same In Bounce Expression (left - right) what is unique in this is, There is some other properties which let's you control where you want you shape after the bounce and it also falls from the top to Bottom.

Shape Layer /Image /Video > Position

// How far off-center the initial drop is (pixels) initialDrop = 200; // How much bounce amplitude after the drop (pixels) bounceArea = 50; // Bounce frequency (bounces per second) and decay freq = 5; // CHANGED: 100 was too fast (invisible vibration) decay = 10; // Time setup t = time - inPoint; duration = 0.5; // Duration of drop phase // Calculate the center position (Y) centerY = thisComp.height / 2; // 1. Calculate drop position // (Moves from 'centerY - initialDrop' to 'centerY' over half duration) basePos = linear(t, 0, duration/2, centerY - initialDrop, centerY); // 2. Calculate bounce (only runs after the drop phase) if (t < duration/2) { bounce = 0; } else { // Time since bounce phase started bounceTime = t - duration/2; // Create diminishing bounce bounce = bounceArea * Math.sin(freq * Math.PI * 2 * bounceTime) / Math.exp(decay * bounceTime); } // 3. Final Output y = basePos + bounce; // Return [x, y] because Position is a 2D property [value[0], y];

Reverse Keyframe /Animation

This expression make the animation in Reverse with the help of Math, which means the Shape layer which was moving in the right direction will now move in the left direction.

Shape Layer > Position

compCenter = thisComp.width / 2; newX = (compCenter - transform.position[0]) + compCenter; [newX, value[1]];

Any Property

Single-Segment PingPong

Loops the animation back and forth using only the last two keyframes.

Any Property

loopOut(type = "pingpong", numKeyframes = 1)

Continuous Offset Loop

Creates a never-ending animation by adding the last keyframe's value to the next cycle. Perfect for infinite scrolling or rotating.

Any Property

loopOut(type = "offset", numKeyframes = 0)

Seeded Low-Fi Random

Generates a unique, stepped random value for each layer. Using seedRandom ensures each layer gets a different result, while posterizeTime controls the "jitter" speed.

Any Array Property

posterizeTime(2); seedRandom(index, false); r = random(200, 100); [r, r] // Tells AE to use the random number for both X and Y

Any Scalar Property

posterizeTime(2); // The "Speed" of the change (2 times per second) seedRandom(index, false); // The "Unique ID" (index) and "Motion" (false) random(0, 10); // The "Range" (Minimum, Maximum)

Dynamic Ease Mapping

Maps time to a value range with built-in easing. Unlike a linear transition, this starts slowly and decelerates at the end for more natural movement.

Any Property

ease(time, 0, 5, 0, 100);

Dynamic 3x5 Auto-Scaling Shape Grid

This setup creates a grid of 15 shapes (5 columns by 3 rows) that you can control globally using a single Null Object. By using expressions, you can adjust the size, spacing, and selection of the shapes without having to edit each layer individually.

Shape Layer > Scale

// variables // var select = thisComp.layer("controls").effect("Select")("Slider"); var padding = thisComp.layer("controls").effect("Padding")("Slider"); var id = thisLayer.index; // calculations // if (select > id) { x = ease(select, id, id + padding, value[0]*thisComp.layer("controls").effect("the size of the shape")("Slider"), value[0]); } else { x = ease(select, id - padding, id, value[0], value[0]*thisComp.layer("controls").effect("the size of the shape")("Slider")); } // outputs // [x,x]

Dynamic Multi-Layer Index Rotation

This expression automates the rotation of multiple layers based on their stack order. It creates a responsive, procedural animation controlled by a single "CONTROLLER" Null.

Select: Adjusts the base rotation or target layer focus.
Padding: Sets the rotational offset (gap) between each layer.

Shape Layer > Rotation

var select = thisComp.layer("#CONTROLER").effect("Slider Control")("Slider"); var padding = thisComp.layer("#CONTROLER").effect("Slider Control 2")("Slider"); var id = thisLayer.index; if (select > id) {x=ease(select,id,id+padding,value+360,value);} else {x=ease(select,id,id-padding,value,value+360);} x
