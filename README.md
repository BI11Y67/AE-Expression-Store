# 🚀 AE Expression Store
> **The ultimate copy-paste library for Motion Designers.**

![License](https://img.shields.io/badge/license-MIT-blue.svg) ![Tech](https://img.shields.io/badge/built%20with-Tailwind%20%7C%20JS-06b6d4.svg) ![Status](https://img.shields.io/badge/status-active-success.svg)

**AE Expression Store** is a lightweight, web-based library designed to speed up your After Effects workflow. Instead of searching forums or rewriting the same `wiggle()` code for the 100th time, just open this local tool, search, and click to copy.

---

## 🌟 Features

* **⚡ Instant Copy:** One-click copy for complex expressions.
* **🎨 Visual Previews:** See exactly what the expression does before you use it.
* **🧠 Logic-First:** Includes "Math breakdown" for complex physics scripts.
* **🌗 Dark Mode:** Built with a sleek, eye-friendly dark theme using Tailwind CSS.
* **📂 Organized:** Cleanly separated into Physics, Loops, and Utility categories.

---

## 🛠️ Included Expressions

This library currently includes:

| Category | Expression | Description |
| :--- | :--- | :--- |
| **Physics** | `Inertial Bounce` | Adds organic bounce to any keyframed motion. |
| **Physics** | `Proximity Force Field` | Pushes layers away based on distance from a master layer. |
| **Looping** | `Seamless Wiggle` | A wiggle that loops perfectly for GIFs/Lottie. |
| **Utility** | `Path Flow Distributor` | Distributes multiple layers along a path automatically. |
| **Utility** | `Maintain Stroke` | Keeps stroke width constant while scaling. |

## 🚀 Quick Start

You don't need to install anything! This is a static web tool.

1.  **Clone the repo** (or download the ZIP):
    ```bash
    git clone [https://github.com/YOUR_USERNAME/AE-Expression-Store.git](https://github.com/YOUR_USERNAME/AE-Expression-Store.git)
    ```
2.  **Open `index.html`** in your browser.
3.  **That's it!** No servers, no Node.js required.
